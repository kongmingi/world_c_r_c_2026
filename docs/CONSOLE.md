# 시리얼 명령

시리얼 모니터 115200, 줄 끝 개행. USB와 블루투스(Serial2) 둘 다 입력할 수 있고, 출력도 양쪽으로 나갑니다. `help`를 치면 목록이 나옵니다.

## 측정 · 확인
| 명령 | 하는 일 |
|---|---|
| `psd` | PSD 4개 값 + 전방 평균(avg) + FR−FL 출력 |
| `t1` | 센서 모니터: PSD와 카메라 블록(sig, x, y, w, h, dx, 화면 범위 IN/out). 아무 키나 누르면 멈춤 |
| `check` | 모터 응답, 전압 등 점검 |
| `lamp1` / `lamp0` | Pixy 램프 켜기 / 끄기 |
| `inv` / `inv clear` | 적재함 기억 지도 보기 / 지우기 |

## 팔
| 명령 | 하는 일 |
|---|---|
| `p 이름` | 자세로 이동 (travel carry order orderl orderr hub scan1~3 pa1~3 pg1~3 za1~8 zb1~8, 번호도 가능 예: `p 3` = drive) |
| `j1 +20` / `j1 2047` | 관절 하나를 상대 / 절대 이동 (j1~j4) |
| `arm a b c d` | 4관절을 한 번에 |
| `free` / `lock` | 토크 끄기(손으로 움직이기) / 켜기 |
| `pose` | 현재 관절 값 출력 |
| `save 이름` | 현재 자세를 RAM에 저장하고 Tuning.h에 붙여 넣을 줄 출력 (전원을 끄면 사라짐) |
| `list` | 모든 자세 값 출력 |
| `grip 700` | 그리퍼를 그 값으로 |

## 이동 · 정렬
| 명령 | 하는 일 |
|---|---|
| `move F 300` | 앞(F)/뒤(B)/왼(L)/오른(R)으로 mm 이동 |
| `turn L` / `turn R 2` | 90° 회전 (+보정 각도) |
| `fr 312` | FR PSD로 앞뒤 정렬 |
| `sl 222` / `sr 284` | 측면 PSD로 좌우 정렬 |
| `rot 306 -3` | 정면 평균과 FR−FL을 함께 정렬 |
| `col 2` | 지금 몇 열 앞인지 알려 줌 (손으로 옮긴 뒤) |
| `c1 3` / `c1` | 3열(또는 기억한 열)에서 1열로 가서 정렬 |
| `w`, `wf/wb/wl/wr a b c d` | 바퀴 비율 보기 / 바꾸기 (전원을 끄면 사라짐) |

## 구간 시험
| 명령 | 하는 일 |
|---|---|
| `t2` | 이동 거리 시험 |
| `t3 층 색` | 지금 열에서 그 층 그 색 집기 (예: `t3 2 1`) |
| `t3 A 5` / `t3 B 5` | 그 자리에서 Zone A/B 5번 칸 자세로 낙하 |
| `t4 색` | 지금 열부터 탐색해 그 색 찾아 집기 |
| `t5 1` | 출발 → 장애물 앞 정렬 |
| `t5 2` | 미션지시 Zone으로 이동 → 순서 읽기 |
| `t5 3` / `t5 3 N` | 1열 도착 / N열로 이동 |
| `t5 4 N` / `t5 5 N` | 지금 열에서 Zone A / B의 N번 칸으로 가서 낙하 후 복귀 |
| `t5 6` | Finish로 |
| `t6` | 1열부터 적재함 탐색만 |
| `t7` | 경기 전체 (SW1과 같음) |

## 배정표
| 명령 | 하는 일 |
|---|---|
| `zone` | 지금 배정표 보기 |
| `zone 빨 A1 노 B5 …` | EEPROM에 배정표 저장 (업로드 없이 반영) |
| `zone clear` | EEPROM 배정표 지우고 Tuning.h 표로 |

정지: 경기·명령 중 **SW2**를 누르면 바퀴 토크를 끄고 대기 상태로 돌아갑니다.
